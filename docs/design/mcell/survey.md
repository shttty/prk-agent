## 有没有「并发共享变量 + 单独硬杀」？

**推断：在上述样本中，没有看到两者同时适用于任意 cell。** 这里的“共享”指 A/B 同时看见同一个普通可变对象的修改；“硬杀”指不要求 A 的解释器或原生调用配合，监督者可终止 A 并确认退出，同时 B 和主 namespace 存活。OMP/JEP 91 有前者，没有后者；按命令起进程有终止边界，但共享的是工作区或显式数据。子 agent 的会话历史、可续写的 PTY、可查询的 job ID 都不是解释器共享堆。

### 从主 Python kernel fork：得到快照，不是共享对象

- **复制边界。** Linux `fork` 产生各自地址空间，普通私有页起初 COW；child 改列表、重新绑定变量，父与兄弟均不会看见。fd 却指向同一 open file description，共享文件偏移等内核状态。杀进程不能撤销已写文件、已发送字节或数据库提交。[Linux fork(2)](https://man7.org/linux/man-pages/man2/fork.2.html)
- **线程与锁。** child 只有调用 fork 的线程，却继承其他线程可能已锁住的 mutex；多线程程序 fork 后至 exec 前，POSIX 只允许 async-signal-safe 函数。CPython 3.12 能检测时警告，3.14 起没有平台以 fork 为默认启动方式。PRK 现有 runner 自己就启动 `prk-input` 线程（`src/kernel/runner/assemble-runner.py:39–47`），不必等用户代码创建线程才有问题。[os.fork](https://docs.python.org/3/library/os.html#os.fork) · [启动方式](https://docs.python.org/3/library/multiprocessing.html#contexts-and-start-methods)
- **asyncio、SSL 和数据库。** CPython 在 child 清理 running loop 和 wakeup fd；不能把父 loop 中的任务当成已迁移。[CPython `events.py:873–881`](https://github.com/python/cpython/blob/3.14/Lib/asyncio/events.py#L873-L881)。TLS socket 的 fd 指向原连接，但用户态协议状态已复制；Python 还专门提示 fork 与 OpenSSL PRNG 的约束。[ssl 多进程说明](https://docs.python.org/3/library/ssl.html#multi-processing)。SQLAlchemy 明确禁止跨 fork 复用池中 TCP 连接；建议 child 重建池，如 `dispose(close=False)`，不跨进程共享已借出的连接或事务。[连接池指南](https://docs.sqlalchemy.org/en/20/core/pooling.html#using-connection-pools-with-multiprocessing-or-os-fork)
- **内存。** fork 仍复制页表；后续写脏按页分摊，连 GC 扫老对象也会破坏 COW。`gc.freeze()` 可减少特定 GC 写入，不会把用户图变成只读共享对象。[fork(2)](https://man7.org/linux/man-pages/man2/fork.2.html#NOTES) · [gc.freeze](https://docs.python.org/3/library/gc.html#gc.freeze)。**推断：**单管理核能重叠 I/O，不能凭进程数增加 CPU 吞吐；按并发数实测 cgroup 总 charge、峰值及各进程 PSS/Private_Dirty，不要把 RSS 相加，也不要按启动时的 COW 折扣给内存保底。
- **推荐（推断）。** 保留常驻 kernel 给确需共享对象的串行 cell；必须独立硬停的并发 cell，用新解释器或干净、单线程的 forkserver，显式传入/返回小数据，大结果留在目标机。forkserver 的快照属于 server，不是实时 REPL。成功返回才由主 kernel 显式提交选定变量；同名更新拒绝或要求选择，取消不写回。以 cell 独立进程组/可用的 cgroup 管子孙、等退出再报 stopped；直接 `Process.kill()` 不会杀尽后代，终止持锁或写共享队列的 worker 也可能伤及同伴。[multiprocessing 终止警告](https://docs.python.org/3/library/multiprocessing.html#multiprocessing.Process.terminate) · [既有 PRK 实测](research-bun.md)。
