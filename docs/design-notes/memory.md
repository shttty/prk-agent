### 可复用工具、技能与证据边界

关联 [模块约定](../wire/tools.md#约定)、[模块约定](../wire/skills.md#约定)、[模块约定](../wire/tools.md#约定)、[模块约定](../wire/skills.md#约定)。原 359、361、363、365、367、369、373、386、388、390、402、408、410、412。

- `@tool` 的 `source`、`signature`、`docstring` 与 `imports` 在目标端用标准库 `inspect`、`ast` 提取，不在网关写第二个 `Python` 解析器；闭包或非导入全局变量须显式参数化或移入函数。
保存不在宿主执行；加载的函数在当前单元执行后，经回调记录成功。
内部 `prk_library_*` 传输不出现在模型可调用接口中，这是防误用，不是同一可信 `Python` 进程的安全边界。
- `successfulCalls` 是展示总次数：同一会话三次成功得到 `calls=3`、`distinctSessions=1`，状态仍为 `staging`；失败不增加。
它不参与晋升、空闲老化或容量竞争。
原文提到旧工具记录不迁移、当时日常工具库为空，这是一次切换状态，不是后续清空数据的承诺。
工具可用性来自每个目标的真实导入尝试，不把未知猜成可用；装包后可用 `library_sync` 刷新。
- 工具生命周期在网关启动或访问时做低成本检查，不加守护进程或队列；只有人工晋升获得的人工保护免于老化与溢出淘汰，同名修订保留。晋升容量全被人工项占满时，自动项保持 `staging`，人工晋升明确报满。技能类似，但只保留当前文件树，不另建版本史；编辑保留读取会话统计与人工晋升。
- 技能创建以结构化文本生成安全引用的 `YAML` 与固定章节；标题、代码围栏字符被转义，多行列表项缩进，模型不手写整份 `SKILL.md`。补丁只替换固定章节，前置元数据与正文成对更新，其他部分保留；目标标题重复或缺失时明确拒绝，包括标题仅出现在代码围栏示例中的情况。
旧的 `content`、`oldText`、`newText` 参数已直接移除，不留别名。
示例与字段限制仍在配置参考。
- 原文第 410 行所述关闭 `localTools` 时只有共享技能、读取器仅在网关宿主运行，已经过时。`src/sessions/runtime/tools/create-session-tools.ts` 与目标技能路由已使 `skill_read` 选择实际机器；不把旧行为写成有效规则。
- 读取用量来自公开开发套件 `tool_result` 的实际 `path` 与 `isError`；只有成功读取生效中的受管 `SKILL.md` 才计数，受限或截断读取也算，不解析正文或聚合页。原生 `read` 要求精确的受管绝对路径；`skill_read` 的相对路径按读取器边界解析。广告、发现、管理页读取、支持文件、失败或取消不计数。`disable-model-invocation` 隐藏广告，但不排除显式成功读取。原生 `bash` 缺少可靠文件身份，`/skill:name` 输入事件早于展开且无成功身份事件，所以两者仍可用但不计用量。读取证据不证明执行、有效性或真实模型学习质量。

### 记忆审查与输入计数边界

关联 [模块约定](../configuration.md#约定)、[模块约定](../wire/memory.md#约定)。原 312、325、335、337、339、341、343。

- `soul` 是操作者人格；`control` 是跨任务工作规则、边界、权限与偏好；`user` 是身份事实，`memory` 是通用持久事实，`instance` 是绑定机器的事实；任务进度、一次性脚本和当前状态不进入这些层。任务类别的方法、判断、陷阱与修正放入技能，可再次调用的确定函数放入工具并说明复用原因。
- 记忆写入同步重读，先规划整批操作与最终容量，再暂存文件并重命名；发生输入输出错误时回滚已发布文件，但不是抗崩溃的跨文件事务。没有文件锁、注入扫描器或数据泄漏防护；单网关自身同步串行操作。
- 审查使用主回复结束时的模型与上下文快照，只开放记忆工具；`control` 成功变更即时显示前后对比通知，其他目标在审查写入后汇总通知，原生自定义消息不触发新模型回合。后台错误只记诊断；关闭会话时中止并等待在途审查。
- 原文第 341 行按 `Pi 1.3.0` 已完成用户角色消息的来源缺口，解释为何会计入同伴消息；实际 `src/sessions/memory-runtime.ts:102` 依据公开输入来源，统计非扩展输入，不是检查已完成的用户角色消息。同伴消息也可能计入；严格只统计人类输入，仍需产品或接口决策。
不能依据消息文本猜测人类身份。
